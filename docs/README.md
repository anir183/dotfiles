# dotfile

my linux dotfiles and configs for different software. managed using
[chezmoi](https://www.chezmoi.io).

### configs
* bat
* github cli
* ghostty
* git
* luarocks
* niri
* fish
* user-dirs
* wgetrc
* zellij
